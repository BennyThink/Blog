# 03 · 导出与备份准备

状态：待开始；本阶段暂不要求导出。

目标：拿到可离线试迁移的内容与媒体副本，保持线上站点正常运行。

## 由站点所有者在线上准备

- [ ] WordPress 后台「工具 → 导出 → 所有内容」，下载 WXR/XML。
- [ ] 打包完整 `wp-content/uploads/`，保留年份、月份等目录结构。
- [ ] 记录导出时间、WordPress 版本、固定链接格式、内容数量。
- [ ] 根据第 02 步确认的功能，补充菜单、主题设置和插件专有数据。

XML 包含附件 URL，不包含媒体文件二进制。评论和插件专有数据需要在试导入时逐项确认；若 WXR 不足，再决定补充导出方式。不预先要求数据库、账号或密钥。

## 本地接收与检查

- [ ] 将真实导出文件存放在 Git 与 Docker 构建上下文之外。
- [ ] 为原始压缩包和 XML 计算校验和，保存只读副本。
- [ ] 检查 XML 可解析、媒体目录完整，并记录文章、页面、分类、标签和附件数量。
- [ ] 导入前备份当前本地 `data/`、`uploads/` 及 `.env`。

## 完成标准

输入文件完整、来源与时间可追溯；导入可以从副本重复执行。线上导出和备份由所有者操作，迁移程序不访问线上后台。
