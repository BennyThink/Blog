# 06 · 迁移验收

状态：待开始。

目标：以真实迁移内容验证功能、数据和日常运维，形成上线前的问题清单。

## 执行清单

- [ ] 对账文章、页面、分类、标签、作者、媒体及需要保留的评论数量。
- [ ] 抽查正文、图片、代码、表格、内部链接和特殊区块。
- [ ] 验证旧 URL 到新 URL 的映射、301、404 和中文路径。
- [ ] 验证首页、文章、归档、搜索、RSS、SEO 元数据和导航。
- [ ] 所有者注册 Passkey 后，测试后台登录、编辑、预览和媒体上传。
- [ ] 配置评论审核策略；若不保留评论，同时移除开关与 UI。
- [ ] 在真实数据副本上验证 bind mount、容器重建及备份恢复。
- [ ] 检查移动端、深色模式、可访问性和明显性能问题。
- [ ] 记录通过项、已知差异和必须修复的问题。

## 完成标准

关键问题修复；所有者确认迁移内容与保留功能符合预期；备份可恢复。当前示例数据验收脚本会实际重建容器并写入临时标记，真实环境执行前需确认适用范围并先备份。
