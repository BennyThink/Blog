### 本地核对依据

参考根目录：`WordPress-root/wp-content/themes/WordPressGit-master/`。

- `inc/theme-options.php`：上述功能开关与配置项；其中混合头像说明了回退顺序。
- `functions.php`：面包屑、评论过滤、图片灯箱及 Telegram 发布通知代码。`send_new_post` 监听 `transition_post_status`，仅在文章从非发布状态进入发布状态时发送通知。
- `footer.php`：Telegram 社交入口及 pangu 脚本加载。
- 已读取参考文章的公开页面内容，但尚未进行桌面/移动端截图与交互验收。

### 已确认的分工与范围

- 登录仅供所有者本人使用，不建设读者注册、登录及账号迁移流程。
- 公告、占位文本、SEO、版权声明、社交地址、统计与头尾代码等实际配置值由所有者自行复制粘贴。保留相应配置入口，不再索要配置截图或导出，不以配置值缺失阻塞开发。
- Telegram chat id、bot token 同样由所有者自行配置；token 使用服务端秘密配置，不写入本文档。
- 评论已经存在，本次不处理现有评论的迁移、审核状态或数据修改；此前明确要求的垃圾评论屏蔽、评论占位文本及混合头像功能仍在保留范围内。黑名单等实际值由所有者自行填写。
- 动态格言来源、分享平台与 Telegram 通知行为先按本地主题及旧站盘点，不作为当前必须由所有者补充的输入。

### 待继续盘点（可由本地资料与公开页面推进）

- 首页、归档、独立页面、搜索、侧栏、菜单及移动端视觉与交互。
- 文章、页面、分类、标签、媒体、作者及特殊字段映射；现有评论数据不在本次处理范围内。
- 短代码与依赖插件的特殊内容；RSS、搜索及其他未列明功能的去留。
- 当前仅确认一个 `.html` 文章 URL 样本，不据此推断全站固定链接规则。整理更多文章/分类/标签/分页 URL 后，确定保留原路径还是重定向。
- 文章导入不得触发历史文章的 Telegram 批量通知。
