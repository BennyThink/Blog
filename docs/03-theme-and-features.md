# 05 · 主题与功能移植

状态：待开始，等待第 02 步确认功能范围。

目标：将确认要保留的视觉和交互移植到 EmDash，不直接运行 WordPress 主题。

## 执行清单

- [ ] 基于旧主题与截图明确首页、列表、文章和独立页面的目标效果。
- [ ] 在 `src/styles/theme.css` 覆盖设计 token，遵守项目视觉约束。
- [ ] 保留 frame/band 对齐和桌面文章三栏阅读布局。
- [ ] 逐项实现菜单、侧栏、特殊页面和确认需要保留的交互。
- [ ] 对特殊内容使用明确的 Portable Text 区块或 EmDash 插件实现。
- [ ] 检查浅色/深色、桌面/移动端、键盘操作和长文排版。
- [ ] 所有 CMS 内容保持服务端渲染，图片使用 EmDash 图片对象与组件。

## 完成标准

第 02 步保留功能逐项有实现和验收说明；不支持或有差异的功能明确列出，不把旧主题代码中的依赖默认纳入范围。
