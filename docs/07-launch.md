# 07 · 上线与回退

状态：待开始；需要所有者明确上线指令后执行。

目标：在最终数据同步和恢复演练完成后切换流量，并保留可操作的回退路径。

## 上线前准备

- [ ] 确认服务器、域名、HTTPS、反向代理及停机窗口。
- [ ] 在正式主机创建 bind mount 目录并配置 UID/GID 1000:1000 写权限。
- [ ] 安全配置 `.env`，构建和运行时使用一致的 `EMDASH_SITE_URL`。
- [ ] 设置数据库、上传目录和加密密钥的备份与恢复流程。
- [ ] 完成第 06 步验收和恢复演练。
- [ ] 确定内容冻结时间、最终导出与增量同步方式。

## 经明确上线指令后执行

- [ ] 所有者生成最终旧站备份与导出，本地核对后导入正式环境。
- [ ] 最终抽查内容、媒体、管理员访问和重定向。
- [ ] 按确认方案切换反向代理或 DNS。
- [ ] 观察错误日志、404、搜索、RSS 和关键页面。

## 回退方案

切换前记录原 DNS/代理配置并保持旧站与备份可恢复。明确触发回退的条件、操作人和切回步骤；上线后若产生新内容或评论，先保存增量，再按既定方案回退，避免覆盖新数据。

## 完成标准

线上关键路径验证通过，备份及回退责任清晰；旧站保留期由所有者决定。本故事的创建不代表授权修改线上站点。
