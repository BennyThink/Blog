# 02 · 旧站盘点与功能取舍

状态：待提供保留功能清单。

目标：在导入和移植前明确范围、内容模型与 URL 兼容要求。

## 输入

- 所有者提供需要保留、可替换、可移除的功能。
- 本地参考主题：`WordPress-root/wp-content/themes/WordPressGit-master`。
- 旧站固定链接格式、菜单结构、关键页面截图。

## 执行清单

- [ ] 盘点首页、文章、归档、独立页面、搜索、侧栏和移动端。
- [ ] 盘点主题短代码、文章自定义字段及依赖插件的功能。
- [ ] 确认评论、作者信息、SEO、RSS、站内搜索及外部服务的保留范围。
- [ ] 将每个保留功能映射到 EmDash 内置功能、模板改造或独立插件。
- [ ] 明确文章、页面、分类、标签、媒体与特殊内容的字段映射。
- [ ] 记录旧 URL 样本及目标路由，形成重定向清单。

## 完成标准

功能范围和内容映射可逐项验收；不确定项有明确记录。此步骤只分析本地参考资料，不执行旧 WordPress PHP，不安装线上插件或修改线上设置。

下一步：[03 · 导出与备份准备](03-export.md)。
