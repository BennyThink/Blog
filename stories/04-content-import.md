# 04 · 内容与媒体试迁移

状态：待开始。

目标：先在独立测试目录导入代表性真实内容，验证映射后再进行完整导入。

前置：第 02 步内容映射确定，第 03 步导出副本可用。

## 执行清单

- [ ] 核对当前版本官方导入文档，选择可离线执行的导入方式。
- [ ] 使用独立的数据库及上传目录，保留现有示例环境与备份。
- [ ] 选取含图片、代码、表格、短代码、中文链接和评论的代表性文章。
- [ ] 验证 HTML/Gutenberg 到 Portable Text 的转换及自定义块需求。
- [ ] 映射 slug、发布日期、作者、分类、标签、摘要与特色图片。
- [ ] 从本地媒体副本导入图片，替换正文中的旧媒体 URL。
- [ ] 输出未支持的短代码、字段、区块与丢失媒体清单。
- [ ] 试导入通过后完整导入，记录数量、失败项与重跑策略。

## 完成标准

导入结果可重复；记录与媒体数量可对账；正文及图片能在本地查看；未解决的转换问题有清单。不得把线上旧站作为运行时媒体依赖。
